# Lumi (.NET)

Lumi is a small educational programming language implementation written in C#/.NET. It is a hobby project intended to explore language design, parsing, bytecode generation and a simple virtual machine for executing the generated bytecode.

This repository contains several projects that together form the compiler/runtime toolchain:

- `Lumi.Ast` — Abstract Syntax Tree (AST) node types and helper structures (`Position`, `Span`, nodes for expressions/statements, etc.).
- `Lumi.Lexer` — Lexer/tokenizer that converts source text into a stream of tokens.
- `Lumi.Parser` — Parser that consumes tokens and builds the AST.
- `Lumi.Bytecode` — Bytecode definitions, constant pool and a bytecode generator that visits the AST and emits instructions.
- `Lumi.VM` — A simple stack-based virtual machine that executes the Lumi bytecode.
- `Lumi.Parser.Tests`, `Lumi.Lexer.Tests` — Unit tests for lexer/parser (MSTest projects).

## Getting started

1. Open the solution in Visual Studio 2022/2026 or run `dotnet build` from the repository root (projects target .NET 10).
2. Run tests from Test Explorer or `dotnet test`.
3. See `Lumi.VM` for a small virtual machine and example code showing how to load bytecode and run it.

## Design notes

- The compiler pipeline is split into lexer → parser → bytecode generator → VM.
